# Quick note

Save what the user dictated as a note in the workspace.

1. The file is `notes/YYYY-MM-DD.md`, named for today's date. Create `notes/` and the file if they do not exist.
2. Append one bullet to the file: `- HH:MM — <the note>`, using the current local time.
3. Keep the user's wording. Fix obvious speech-recognition mistakes, and nothing else.
4. Confirm in one short sentence, for example "Noted." Do not read the note back unless asked.
