# sessions/

This folder is the **working directory** of Jar-vis sessions in opencode.

opencode does not store transcripts here. It keeps sessions in its own data
directory (`~/.local/share/opencode`), keyed by project and directory. Using this
folder as the working directory is what groups Jar-vis sessions together and gives
them their own agents and skills.

- `.opencode/` is generated by Jar-vis from `assistant/agents` and `assistant/skills`. Do not edit it.
- `AGENTS.md` is generated once and is yours to edit.
- `notes/` is where the `quick-note` skill saves notes.
